# Skill Center 指标口径 V1

所有业务日按 `Asia/Shanghai` 切分。事件以 `occurredAt` 归属统计周期，以 `receivedAt` 诊断迟到和补报；同一机器主体下相同 `eventId` 只计算一次。

| 指标 | 计算规则 | 不包含 |
| --- | --- | --- |
| 已发布 Skill 数 | 当前至少有一个 `published` 或按权限可见的 `deprecated` 版本的去重 Skill 数。 | 仅校验失败、待审核、驳回、下架的 Skill。 |
| 累计安装次数 | `action=install` 且 `outcome=success` 的去重事件数。 | 升级、降级、卸载、ZIP 下载。 |
| 当前安装数 | 对“用户 + 匿名设备 + Skill”按发生时间和接收顺序取最后有效状态，最后状态不是卸载的数量。 | 仅下载 ZIP、失败安装。 |
| ZIP 下载次数 | 权限校验通过且下载响应完成的去重下载事件数。 | 安装、清单获取、下载失败。 |
| 调用次数 | 通过 Schema 和质量规则的去重调用事件数。 | 被拒绝、被隔离、重复事件。 |
| 活跃用户数 | 统计期内至少有一次 `status=success` 调用的去重用户数。 | 只有失败、取消或超时的用户。 |
| 调用成功率 | `success ÷ (success + failure + timeout)`。 | `cancelled` 单列，不进入分母。 |
| P95 耗时 | 统计期内通过质量规则的 `durationMs` 第 95 百分位。 | 负数、超上限、隔离事件。 |
| 版本采用率 | 某版本当前安装数 ÷ 该 Skill 全版本当前安装数。 | 分母为零时显示“无数据”，不显示 0%。 |

环比使用等长前一周期；自定义日期范围也取紧邻的等长前期。市场总览指标按当前用户可见范围计算，治理看板按角色和团队数据范围计算。

调用明细默认保留 180 天，安装/下载明细默认保留 1 年，脱敏日汇总与审批审计默认保留 3 年。正式留存期限以部门制度为上限约束，管理员不得配置得低于制度要求。
