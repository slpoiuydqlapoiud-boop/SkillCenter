## 使用说明

建议每条记录填写：`通过 / 失败 / 阻塞`，并补充实际结果、截图和复现步骤。涉及权限的用例至少执行两遍：普通开发者、平台管理员。

## 十、异常、安全与数据边界

| ID | 操作 | 预期结果 |
| --- | --- | --- |
| EDGE-01 | API 断开后访问只读页面 | 页面显示可理解的错误和重试入口，不白屏、不把 API 请求变成 HTML。 |
| EDGE-02 | API 返回 400/401/403/404/409/429/500 | 前端展示统一错误提示，不显示堆栈或内部路径。 |
| EDGE-03 | 快速连续点击发布、收藏、创建、审核 | 不产生重复提交；按钮有 loading/禁用状态。 |
| EDGE-04 | 使用另一个用户 ID 访问他人通知/个人数据 | 返回空数据或无权限，不越权。 |
| EDGE-05 | 输入 HTML/脚本字符串到搜索、名称、描述、驳回原因 | 页面按文本展示，不执行脚本。 |
| EDGE-06 | 修改 URL 路径访问不存在页面 | 返回应用空状态或 404 处理，不出现服务器错误页。 |
| EDGE-07 | 上传超大 ZIP、压缩包嵌套或恶意路径 | 被限制/拒绝；不发生目录穿越或资源失控。 |
| EDGE-08 | 检查浏览器网络请求 | 不在通知、统计、审计或错误响应中出现 Token、Prompt、Skill 正文、密码。 |
