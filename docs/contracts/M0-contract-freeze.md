# M0 需求与契约冻结记录

## 冻结结论

一期范围保持为内部 Skill 的上传、校验、审核、发布、检索、安装、调用统计、废弃、下架和审计。网页不创建或编辑 Skill，不存在草稿状态；平台不在线执行或调试 Skill。

## 已冻结契约

- `skill.json` Schema V1。
- 安装清单 Schema V1。
- 安装事件 Schema V1。
- 调用事件 Schema V1。
- Skill 目录和 ZIP 单根目录规则。
- SemVer、RFC 3339、SHA-256 和 `Asia/Shanghai` 统计规则。
- 低/中/高风险和高风险双人审核规则。
- 安装、下载、调用、活跃用户、成功率和版本采用率口径。
- 调用数据白名单与禁止采集字段。

## 变更控制

M0 之后，任何 Schema 修改必须：

1. 建立变更记录，说明生产者、消费者和迁移影响。
2. 为新行为先添加失败的契约测试。
3. 明确兼容或不兼容；不兼容变更使用新的 Schema 主版本。
4. 由平台后端、客户端、数据和安全责任人共同评审。
5. 更新有效/无效样例、文档和发布说明。

## M0 验收证据

- 四个 JSON Schema 均使用 Draft 2020-12。
- 有效样例均通过契约验证。
- 典型非法版本、哈希、失败事件和正文泄漏样例均被拒绝。
- 示例 Skill 包具有单一安全根目录，包含必需的 `SKILL.md`；`skill.json` 可选。
- 自动测试命令和依赖版本已落盘。
