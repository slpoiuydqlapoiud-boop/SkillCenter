# M5.2 受控导出与审计治理基础状态

日期：2026-08-18

## 状态

M5.2 已完成本阶段范围，后端、前端、真实 API 联调和文档收口均已通过。当前实现继续使用本地 JSON 存储，适用于内部开发环境和功能验收；对象存储、限流、防重放、备份恢复和运维告警保留到后续阶段。

## 已交付能力

### 受控导出

- 数据集：`AUDIT_SUMMARY`、`INVOCATION_SUMMARY`、`INSTALLATION_SUMMARY`。
- 格式：UTF-8 CSV/JSON。
- 状态：`QUEUED`、`RUNNING`、`COMPLETED`、`FAILED`、`EXPIRED`。
- 任务元数据、失败码、脱敏字段、相对产物路径和 SHA-256 已持久化。
- 产物目录：`./data/governance/exports`。
- 下载 URL 由短期一次性令牌保护，默认有效 15 分钟；签发、成功下载和拒绝下载均写入审计。
- 导出字段采用后端白名单投影，不导出 Prompt、Skill 正文、响应正文、token、模型名、sessionId、设备标识、凭证或原始 metadata。

### 审计保护

- 角色沿用 `viewer`、`maintainer`、`reviewer`、`admin`；reviewer 映射为审计操作角色。
- reviewer 可读取脱敏审计摘要并创建/下载本人导出任务；admin 可全量查看、重试任务和修改保留策略。
- viewer/maintainer 无导出权限。
- 新审计事件使用 SHA-256 追加链；旧快照首次加载时建立兼容链并支持断链校验。

### 保留策略

- 默认值：审计 365 天、调用 90 天、安装 90 天。
- 安全下限：审计 365 天、调用 30 天、安装 30 天。
- API 支持读取、乐观锁更新、影响预览和带确认令牌执行。
- 执行只清理调用/安装明细；审计事件保留并返回归档资格数量，不在本阶段物理删除审计。

### 前端工作台

- 新增“审计与导出”入口，admin/reviewer 可见，其他角色隐藏。
- 支持创建任务、状态刷新、失败提示、下载、管理员重试。
- 支持保留天数修改、清理预览、二次确认执行和策略版本提示。
- 前端不展示后端绝对路径、堆栈或内部异常信息。

## 主要接口

- `POST/GET /api/v1/admin/exports`
- `GET /api/v1/admin/exports/{jobId}`
- `POST /api/v1/admin/exports/{jobId}/download-url`
- `GET /api/v1/admin/exports/{jobId}/download?token=...`
- `POST /api/v1/admin/exports/{jobId}/retry`
- `GET/PUT /api/v1/admin/retention`
- `POST /api/v1/admin/retention/preview`
- `POST /api/v1/admin/retention/execute`
- `GET /api/v1/audit`：admin 返回完整审计，reviewer 返回脱敏摘要

## 已知边界与后续阶段

- 生产默认打开调用事件本地 JSON 持久化；自动化测试通过测试属性切换为内存存储，避免测试数据污染开发快照。
- 有界线程池当前最大并发 2、队列 20，尚未接入消息队列和独立 worker。
- 产物尚未迁移对象存储，下载限流、一次性签名 URL、密钥管理和容量生命周期属于后续阶段。
- 审计链已支持追加和校验，但审计归档/物理删除、不可抵赖签名和备份恢复尚未纳入本阶段。
- XSS/CSRF、重放防护、统一 SSO、运维监控告警和 RC 门禁仍按 M5.3+ 计划推进。
