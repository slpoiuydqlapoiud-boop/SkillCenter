# M5.3-A API 安全边界状态

日期：2026-08-18

## 本阶段结论

M5.3-A 已完成开发和自动化验证，覆盖 Skill 平台当前高风险写入、授权消费、制品下载、调用上报和导出创建接口。实现保持现有本地 `X-User-Id` / `X-User-Role` 兼容，不引入在线创建或编辑 Skill。

## 已交付

- 固定窗口限流：按用户、客户端或远端地址隔离；返回 `429 RATE_LIMITED`、`Retry-After` 和 `X-RateLimit-*` 响应头。
- Origin 来源保护：仅拦截带 `Origin` 的 `/api/**` 写请求；默认允许本地 Web 来源，无 `Origin` 的 CLI/服务端请求保持兼容；拒绝返回 `403 CSRF_ORIGIN_REJECTED`。
- 安全响应头：API 统一返回 `nosniff`、`DENY`、`no-referrer`、CSP 和 Permissions-Policy。
- 安装与导出幂等：支持可选 `Idempotency-Key`，15 分钟进程内 TTL；重复请求返回 `IDEMPOTENCY_REPLAY`，同键不同请求返回 `IDEMPOTENCY_CONFLICT`。
- 前端错误体验：客户端解析 `Retry-After`，对 429/403 提供可重试和来源校验提示。
- 自动化验证：服务单元测试、MockMvc 契约测试、M5.3-A 安全边界冒烟测试及 Web 客户端测试。

## 已知边界与后续阶段

本阶段限流和幂等状态为单进程内存实现，服务重启或多实例部署不会共享计数/幂等记录。尚未接入 Redis、SSO/令牌校验、对象存储生命周期、监控告警、备份恢复和 RC 门禁；这些内容保留到 M5.3-B/C 及后续上线候选阶段。
