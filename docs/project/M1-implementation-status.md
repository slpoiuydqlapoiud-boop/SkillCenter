# M1 技术底座实施记录

日期：2026-08-17

## 目标

在 M0 契约冻结的基础上，交付一个可运行、可验证、可替换后端的内部 Skill 管理中心前端壳层，覆盖管理、分发和调用统计的主路径。

## 交付项

- Product Design prototype 工程：`apps/web/`。
- 市场首页与详情页：对齐已提供的两张效果图，市场页使用浅色顶栏和侧边导航，详情页使用深色顶栏、无侧边导航的双栏详情布局。
- 角色门禁：viewer / maintainer / reviewer / admin 四种本地演示角色，管理导航按权限显示。
- 上传分发入口：本地 ZIP 上传弹窗，明确 `SKILL.md + skill.json` 包规则，安装、下载、收藏、分享动作有可观察反馈。
- 调用统计入口：调用趋势、成功率 KPI、热门 Skill 表格，数据结构与 M0 invocation-event 兼容。
- 测试与构建：8 个 Node 测试通过，Vite 构建通过，Sites 打包检查通过。
- 设计验收：`design-qa.md`，包含源图、实现截图、视口、响应式和交互证据。

## 明确未包含

本阶段没有接入真实 SSO、组织目录、对象存储、扫描服务、审核 API、Agent/Codex 客户端或生产统计库；页面中的数据和上传结果均为 mock。没有在网站内创建或编辑 Skill，也没有草稿状态。

## 验收结果

- `apps/web`: `npm.cmd test` → 8/8 通过。
- `apps/web`: `npm.cmd run build` → Vite 与 Sites 构建产物生成。
- 浏览器：市场筛选、详情跳转、角色门禁、上传弹窗、统计页、移动端无横向溢出均已验证；控制台无错误/警告。
