# M4.3 生命周期与个人中心状态

日期：2026-08-17

M4.3 已完成版本生命周期控制、下架分发拦截、版本影响面查询，以及绑定当前 actor.userId 的个人中心真实数据接口和页面。

## 已交付

- `SkillVersion` 持久化 `statusReason`、`replacementVersion`、`statusChangedBy`、`statusChangedAt`；旧构造函数和旧治理 JSON 兼容。
- `GovernanceSnapshot` 增加收藏快照，收藏新增/删除幂等并写入 `FAVORITE_ADDED`/`FAVORITE_REMOVED` 审计。
- 生命周期 API：
  - `POST /api/v1/skills/{skillId}/versions/{version}/deprecate`
  - `POST /api/v1/skills/{skillId}/versions/{version}/withdraw`
  - `GET /api/v1/skills/{skillId}/versions/{version}/impact`
- 状态迁移仅允许 `published -> deprecated/withdrawn`、`deprecated -> withdrawn`；原因必填，替代版本必须属于同一 Skill 且为 published/deprecated。
- withdrawn 版本从普通市场隐藏，并阻断新授权、Manifest、制品下载，统一返回 `410 WITHDRAWN_VERSION_UNAVAILABLE`；历史安装、调用和审计保留。
- deprecated 版本继续展示和分发，Manifest 携带生命周期原因与替代版本；版本历史普通用户可见 published/deprecated，管理员可见 withdrawn。
- 影响面聚合安装历史、活跃安装、用户/团队、客户端类型、当前进程调用数和活跃调用用户。
- 个人中心 API：
  - `GET /api/v1/me/installations`
  - `GET /api/v1/me/skills`
  - `GET/PUT/DELETE /api/v1/me/favorites[/{skillId}]`
  - `GET /api/v1/me/invocations`
- 前端已接入真实个人收藏、我创建的、安装记录、调用历史；详情收藏支持 PUT/DELETE 乐观更新失败回滚；版本历史提供管理员废弃/下架弹窗和影响面摘要。

## 有意保留的边界

- 调用影响面和个人调用历史继续复用当前进程 `InvocationEventService`；服务重启后历史归零，后续迁移数据库/分析仓库时保持字段和错误码不变。
- 本阶段没有通知中心、自动迁移安装、SSO/JWT、数据库/消息队列，也没有在线创建或编辑 Skill；Skill 仍只允许本地 ZIP 上传。
- 个人中心的“我的 Skill”依据 owner/team/uploadedBy 关联当前用户并去重；管理员也只能通过 `/me` 查看自己的个人数据。
