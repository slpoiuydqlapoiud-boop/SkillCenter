# M5.1 治理配置阶段状态

日期：2026-08-18

本阶段完成 Skill 平台治理配置第一批能力，范围限定为“管理与分发”所需的团队、角色、字典、合集和平台分页策略。Skill 正文、`SKILL.md`、`skill.json` 仍只能通过本地 ZIP 上传，网站不创建或编辑 Skill。

## 已交付

- `GovernanceSnapshot` 增加治理配置区，旧版 JSON 缺少新字段时自动加载空字典和默认策略；所有既有版本、审核、安装、授权、收藏和审计 mutation 均保留配置快照。
- `GovernanceConfigurationService` 统一处理管理员写入、稳定 ID、角色、团队引用、合集可见性、成员去重、SemVer 和分页策略校验。
- 管理 API：团队、角色绑定、分类、标签、合集及合集成员、平台策略的查询/创建/更新/幂等停用。
- 公开 API：`GET /api/v1/governance/taxonomy`、`GET /api/v1/collections`、`GET /api/v1/collections/{collectionId}`；合集读取支持 public/team 可见范围，详情解析仍处于 published/deprecated 的 Skill。
- 审计动作：`TEAM_*`、`ROLE_BINDING_*`、`CATEGORY_*`、`TAG_*`、`COLLECTION_*`、`PLATFORM_POLICY_UPDATED`。审计 metadata 只记录对象 ID、摘要和 requestId，不记录 Skill 正文、提示词、输出、token 或设备标识。
- 前端治理工作台和真实合集页：管理员可写，reviewer/viewer/maintainer 只读其可见数据；新增 API client、表单校验、冲突提示和空/加载/错误状态。

## 稳定错误码

`CONFIG_CONFLICT`（409）、`COLLECTION_NOT_FOUND`（404）、`SKILL_NOT_FOUND`（404）、`INVALID_REQUEST`（400）、`FORBIDDEN`（403）。DELETE 只停用，不物理删除历史 ID 或成员引用。

## 边界与 M5.2 后续

本阶段仍使用 `X-User-Id/X-User-Role` 本地身份适配器和 JSON 存储，不宣称已接入 Huawei SSO、组织目录或生产数据库。受控导出、审计追加完整性/保留期、限流与重放防护、XSS/CSRF/依赖扫描、监控告警、备份恢复、运行手册及浏览器/键盘/对比度 RC 门禁留待后续 M5.2+ 阶段。
