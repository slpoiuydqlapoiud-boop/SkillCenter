# M5.3-B 运行可观测性状态

日期：2026-08-18

## 本阶段结论

M5.3-B 已完成。平台现在能够在进程内按固定时间窗口聚合 API 请求、延迟和安全边界事件，并为管理员提供运行监控页。指标只保留聚合数据，不记录请求正文、Token、用户 ID 或完整 URL 参数。

## 已交付

- 最近 60 分钟固定 1 分钟桶：请求总数、成功数、4xx、5xx、P50/P95/最大延迟。
- 安全事件计数：`RATE_LIMITED`、`CSRF_ORIGIN_REJECTED`、`IDEMPOTENCY_REPLAY`、`IDEMPOTENCY_CONFLICT`、`EXPORT_QUEUE_FULL`。
- 管理 API：`GET /api/v1/admin/operations/metrics?window=5m|15m|60m`。
- admin-only 权限控制，非管理员返回统一 `403 FORBIDDEN`。
- Web 运行监控页，支持 5/15/60 分钟切换和健康状态展示。
- 冒烟测试覆盖正常请求、Origin 拒绝、限流拒绝、敏感字段脱敏。

## 当前限制

指标保存在单进程内存中，重启清空，多实例之间不共享；P50/P95 使用固定延迟桶近似。当前阶段未接入 Redis、Prometheus、Grafana、外部告警或 SSO。

## 后续 M5.3-C

接入多实例指标聚合、生产监控平台、阈值告警、指标持久化和 RC 门禁，并补充容量与故障恢复验证。
